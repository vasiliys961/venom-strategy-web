# Как задеплоить VENOM Strategy Web (простая инструкция)

Инструкция для тех, кто **не программист**, но хочет запустить веб-версию
ассистента по методу VENOM на Vercel.

## шаг 1. скачайте репозиторий

откройте страницу репозитория на GitHub, нажмите **Code → Download ZIP**,
распакуйте в любую папку.

## шаг 2. заведите аккаунт на Vercel

1. перейдите на https://vercel.com и зарегистрируйтесь (можно через GitHub-аккаунт)
2. это бесплатно для личных проектов такого масштаба

## шаг 3. получите ключ Polza.ai

1. зарегистрируйтесь на https://polza.ai (без VPN, доступно из россии)
2. пополните баланс на 300-500 рублей в личном кабинете
3. скопируйте API-ключ

## шаг 4. настройте хранилище Vercel KV (для сохранения прогресса)

это важно: без этого шага прогресс пользователя может сбрасываться между
запросами. настройка бесплатна на небольших объёмах:

1. в панели Vercel откройте вкладку **Storage**
2. нажмите **Create Database** → выберите **KV**
3. дайте базе имя (например `venom-kv`) и создайте
4. в настройках базы найдите **`.env.local`** снипет — там будут строки
   `KV_REST_API_URL` и `KV_REST_API_TOKEN`, скопируйте их значения

## шаг 5. разместите код на Vercel

самый простой способ — через сайт Vercel:

1. залейте скачанный код в свой репозиторий на GitHub (можно через
   веб-интерфейс GitHub: **Add file → Upload files**, перетащить все файлы)
2. на vercel.com нажмите **Add New → Project**
3. выберите свой репозиторий с этим кодом
4. в разделе **Environment Variables** добавьте:

```
POLZA_API_KEY=ваш_ключ_из_шага_3
POLZA_BASE_URL=https://polza.ai/api/v1
LLM_MODEL=anthropic/claude-sonnet-5
KV_REST_API_URL=значение_из_шага_4
KV_REST_API_TOKEN=значение_из_шага_4
```

5. нажмите **Deploy**

через 1-2 минуты Vercel даст вам ссылку вида `https://ваш-проект.vercel.app`
— это готовый сайт, доступный всем по этой ссылке.

## как пользоваться

просто откройте ссылку в браузере. слева — чат с ассистентом, справа —
визуальная карта VENOM Canvas, которая заполняется по мере диалога. кнопка
"начать заново" сбрасывает прогресс текущей сессии.

## частые проблемы

| проблема | решение |
|---|---|
| сайт не отвечает / ошибка 500 | проверьте `POLZA_API_KEY` в Environment Variables на Vercel |
| прогресс сбрасывается | проверьте, что `KV_REST_API_URL` и `KV_REST_API_TOKEN` настроены правильно |
| хочу поменять модель | измените `LLM_MODEL` в Environment Variables на Vercel и передеплойте (Vercel → Deployments → Redeploy) |

## стоимость

хостинг на Vercel бесплатен для такого объёма трафика (personal-тариф). платите
только за использование нейросети через Polza.ai — рублями, обычно несколько
рублей за диалог.
